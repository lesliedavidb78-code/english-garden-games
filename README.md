# 雾江词语记 · 英语花园

游戏：https://lesliedavidb78-code.github.io/english-garden-games/

草船借箭和单词花园合并成一个网页 App，共享课本词库、水滴、太阳和花园进度。无广告、账号、追踪脚本和学习数据上传。

## 新版玩法

- 小文字持续错落下落，没有大卡片或固定网格；国风绘本雾江和草船插画。
- 朗读英文；英文选项配中文船帆提示，中文选项配英文船帆提示，避免直接显示同语言答案。
- 每词默认20秒，可选10、15、105秒。未提交则时间到自动切词。点中单词立即判题；答对自动射箭，答错自动漏水；答题后立即换词并重置倒计时，不再等时间结束。
- 错选或整题超时增加漏水洞。答对中断连续失误；连续十题失误沉船，已有奖励保留。
- 答对获得一支箭和一个共享水滴；收齐十支箭显示原创诸葛亮人物和“感谢丞相赐箭”。可导入本机录音；没有录音时使用系统朗读，尚未提供影视配音。
- 每十题考核正确至少九题获得一颗太阳；未完成十题的部分不发考核太阳。
- 水滴增加1成长，太阳增加10；100点开花，超额成长转给下一颗种子。
- 题目从学习词库随机抽取，允许复现。花园每道选择题至少两个干扰项来自本课以外；过去的答案也可再次成为干扰项。

## 保存和迁移

主存档键为 `english-adventure-v2`，一次本地写入保存两个游戏和花园。首次运行读取旧键 `english-garden-v1` / `english-navy-v1`，原始旧数据不删除、不覆盖。保留花园库存、成长、收藏、成绩和进行中的学习；借箭保留旧累计箭数、成绩及可转换的未完成题。

旧借箭没有连续失误数据，迁移后漏水计数从零开始。旧成绩作为历史保留，不重新补发奖励。旧入口自动转到合并 App。

家长设置导出全部进度；导入完整备份替换全部进度，导入旧单游戏备份替换对应部分并保留另一个游戏。恢复前提示确认，损坏备份不覆盖数据。不同 iOS 版本或主屏幕图标可能使用不同储存环境，必要时先从原环境导出，再导入新版。

## 文件与验证

- `index.html`、`adventure.js`、`adventure.css`：合并入口和新版借箭。
- `common.js`：独立干扰词库、语音、花园共享存档适配。
- `garden/`：主 App 内的花园；`navy/index.html`：旧入口跳转。旧借箭代码保留以便追溯。
- `assets/`：本轮生成插画；`素材制作记录.md`：制作方向与原始文件。
- `sw.js`：离线缓存v10，只缓存本项目文件。
- `新版验证报告.json`：新版自动化证据。原 `本地验证报告.json` 是前一版证据。

本地运行：在此目录执行 `python -m http.server 8086 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8086/`。离线缓存需HTTPS或localhost。

测试使用桌面Chrome手机尺寸模拟。真实iPhone发音、触摸、主屏幕保存及离线效果尚待设备验收，不能以桌面检查替代。

## 草兵与特效更新

新素材包含六个人形稻草兵；飞箭从点选位置射向草兵，保留插箭、撞击圆环、草屑、船震和合成声音。漏水为持续水柱飞溅，四孔32°、五孔40°倾斜，水位与积水上升；连续十题失误才沉船。具体素材提示词、保存路径见 `稻草士兵素材与特效记录.md`。本轮验证见 `草兵与特效验证报告.json`。真实iPhone声音效果仍需设备验收。

## 即时射出与参考水效更新

点词即计分、正确自动射箭（9.30-09取代旧版手动射出）；正确或错误提交后立即切词并重置计时。正确获得箭与水滴，错误漏水并立即进入可答的新题。保留上一题英文、中文和结果提示，连续两道题不抽同一个词。旧存档已答且等待计时的题目恢复时自动跳过，不重复发奖。

参照用户给的喷水与沉船图制作原创Canvas动画：垂直水柱、顶部伞状分流、重力水滴、下沉飞溅与涟漪，未复制参考图或水印。二维绘本表现不属于物理仿真。证据：`即时射出与水效验证报告.json`，19项本地检查。

## 提示与旧缓存复核（9.30-08）

英文单词雨时船帆显示中文意思；中文意思雨时显示英文。朗读始终是英文。增加当前题号与版本号、检查更新入口。答对或答错均即时进入新题，重置倒计时；换题首帧使用非负时间差，避免旧帧时间戳使20秒短暂显示为21秒。

联网优先获取HTML、JS、CSS，失败回退当前版本缓存；安装预缓存绕过HTTP旧缓存。旧缓存升级激活后导航到新代码，不删localStorage；无需连续两次手工刷新。`提示语与即时换题复核报告.json` 10项检查、`旧缓存升级验证报告.json` 6项检查通过。模拟v7旧页面升级v8保留水滴、成长及当前题。

## 自动射箭与诸葛亮胜利（9.30-09）

取消可见射出按钮；点词自动判题，正确直接飞箭，错误直接漏水，两者立即换题。十题正确后等最后一支箭击中，再显示原创诸葛亮肖像和用户确定的“感谢丞相赐箭”。恢复胜利存档显示人物，不自动播放声音。

`victory-voice.js`允许家长导入MP3/WAV/M4A等浏览器可播放格式，最多10MB；先检测可解码，再用IndexedDB保存到本机。不上传，JSON进度备份不包含音频，移除录音保留学习进度。无录音仍是系统朗读，不承诺影视音色。没有找到许可明确的影视音频；当前无配音生成工具，原创古装男声仍待提供。

验证：`自动射箭与胜利验证报告.json`，19项检查；使用真实鼠标点词，系统语音回调模拟，导入播放测试是静音WAV，不代表自然人声音质或真实iPhone。

## 五年级参考词库扩充（9.30-10）

原始试玩词库三个主题各12词，游戏只抽当前主题。新增PEP五年级参考词库：上册130个、下册155个、上下册合并去重281个词条（含短语），12个单元；可以选全年、单册或单元。默认使用全年综合，主界面与家长设置显示词条数。

版次范围明确：上册第一单元What’s he like?、下册My day。用户已确认重庆学生使用人教版PEP（三年级起点），但尚未确认纸本是否为新版Different friends。人教社当前资源页出现新版Different friends；不能把本次参考词库宣称为2026新版全部词汇。后续需目录或单词表核对新版。

保留原主题词库和自定义词库。旧试玩主题一次升级全年综合；当前题目、历史、奖励、植物成长保持原值；自定义词库不改选，之后手动选主题不再强制升级。家长输入支持4–1000词条，旧存档仍有效。支持星期/月名大写、a.m./p.m.、带连字符和多词短语。花园拼字只抽最多12个字母的单词，听音和草船可练短语，避免大词库导致拼字关拒绝启动。

词库资料见《PEP五年级词库说明.md》；本地验证《五年级词库验证报告.json》。暂未对用户纸本逐页核验，亦不包含课文正文、插图或出版社原音频。

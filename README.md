# 英语小花园与草船借箭

两个独立、可添加到 iPhone 主屏幕的英语小游戏。纯静态 HTML/CSS/JavaScript，无框架、无账号、无广告、无第三方运行脚本。

- `garden/`：拼字搭桥、听音找花、水滴/太阳奖励、种子成长、花朵收藏。
- `navy/`：听英文找英文/中文、下落单词雨、草船收箭、错词补练与战报。
- 两个游戏使用不同的本地存档键，保存每次完整学习记录及当前未完成关卡；支持导出/恢复 JSON 备份。
- Service Worker 预缓存本地资源，以支持首次加载完成后的离线打开。英语发音调用设备语音，离线音频可用性仍取决于设备。

本网站提供游戏程序文件，学习与养成存档不上传。托管服务仍会记录网站文件的常规访问请求。

## 使用

通过 HTTPS 发布后，在 iPhone Safari 分别打开 `garden/` 与 `navy/`，添加到主屏幕。首次从图标打开时保持联网，等出现“离线资源已准备”，再进行飞行模式测试。完整说明见 [使用说明.md](使用说明.md)。

## 本地预览

在本目录运行 `python -m http.server 8086`，用电脑打开 `http://localhost:8086/`。

内置 36 个通用试玩单词；可在家长设置填写课本词汇。真实 iPhone Safari 的触屏、系统语音和主屏幕存档仍需手机验收。

# 英语探险队 · English Adventure Games

**把课本里的英语，变成孩子愿意反复玩的冒险。**

面向小学生的浏览器英语游戏项目。由家庭实际使用反馈推动开发：听单词、认词义、拼写、跟读、对话和句子翻译，融入地图探索、草船借箭、花园养成与房间射击。无需注册，学习进度保存在当前设备。

[立即试玩](https://lesliedavidb78-code.github.io/english-garden-games/) · [任务介绍](PROJECT_BRIEF.md) · [参与贡献](CONTRIBUTING.md) · [迭代路线](ROADMAP.md) · [反馈问题](https://github.com/lesliedavidb78-code/english-garden-games/issues)

## 现在可以玩什么？

| 区域 / 玩法 | 学习内容 | 游戏互动 |
| --- | --- | --- |
| 草船借箭 | 听英文找单词或意思 | 答对自动收箭；答错累计漏水；船队与场景随关卡变化 |
| 单词花园 | 拼字搭桥、听音找花 | 六种种子，各自成长；水滴浇花、太阳加速、成熟花朵收藏 |
| 穿越星门 / 词域探险 | 词义与反应 | 普通或限时模式，词义匹配推动冒险 |
| 地球守护战 | 英语对话 | 剧情对话框、双方血条、答题攻击与五连击大招 |
| 单词守卫 | 词义匹配、听力 | 移动避怪、拾取中文装填、按住拖动瞄准、松手射击、宝箱升级 |
| 英语训练 | 听力、跟读、对话、句子翻译 | 答后保留原答案，显示正确答案，再手动进入下一题 |

**跟读当前支持重复播放示范、本地录音与回听；尚未接入发音评测服务，不会自动判断发音是否标准。** 麦克风使用取决于浏览器权限与 HTTPS / localhost 环境。浏览器的语音识别结果也不能直接充当发音评分。

### 词库与进阶

- 五年级上册以提供的 2024 审定版课本词表照片核对，120 个词条；参考版本与来源见 [词表核对](课本照片核对词表.md)。
- 仅单词守卫扩展到三至五年级六册 PEP 参考词库：684 个原册条目，按英文归一后 626 个词条。三、四年级与五下有新旧版差异，不代表所有学校当前教材。见 [射击词库说明](单词守卫_词库与玩法说明.md)。
- 自由练习遵循家长所选范围；独立闯关按关卡推进。词库有限，全部词条用完后会开启新一轮；无限房间不等于无限词条。
- 草船第 N 关为 N 艘船，需答对 N × 10 题。同一旅程最多累计 10 次漏水，过关不重置；每关正确率独立计算，达到 90% 可获得该关太阳奖励。水滴与太阳先累积，旅程结束统一入账。见 [连续闯关规则](草船连续闯关与浇水说明.md)。
- 单词守卫每个房间 10 题，人物初始 10 点生命；怪物接触也扣血。通过房间获得宝箱，继续探索或结束结算。重试和防护装备的规则见 [玩法说明](单词守卫_词库与玩法说明.md)。

## 5 分钟本地运行

需要现代浏览器与 Python 3。游戏没有构建步骤和运行时 npm 依赖。

```bash
git clone https://github.com/lesliedavidb78-code/english-garden-games.git
cd english-garden-games
python -m http.server 8086 --bind 127.0.0.1
```

打开 **http://127.0.0.1:8086/**。也可以下载仓库 ZIP，解压后在包含 `index.html` 的目录执行最后一行。

直接双击 HTML 无法获得完整的 PWA、离线和麦克风体验。部署可以使用 GitHub Pages 或其他 HTTPS 静态网站服务；不需要账号后端。

## 离线、声音与存档

- 首次联网打开后，等待页面提示离线资源准备完成，再断网使用。当前游戏版本 **10.13-01**，缓存 **english-games-offline-v34**，基础离线清单 919 项，动画兼容资源可能按需加载。
- 播放声音前先点击开始或播放按钮，让浏览器允许音频。手机浏览器和微信 WebView 行为有差异；参考 [安卓发音兼容说明](安卓与微信发音兼容说明.md)。
- 主进度保存在本机 `localStorage` 的 `english-adventure-v2` 中，不跨设备同步。清理浏览器数据或换手机前，请在家长设置导出备份。
- JSON 备份不包含另外保存在 IndexedDB 的自定义谢箭录音，也不包含临时跟读录音。请勿把孩子录音或完整个人存档提交到公开仓库。

## 技术结构与验证

纯 HTML / CSS / JavaScript + Service Worker。各游戏共享词库、存档与奖励，模块位置和改动检查方法见 [贡献指南](CONTRIBUTING.md)。

开发者安装 Node.js 22 或更高版本后，在仓库目录运行：

```bash
node tests/run.mjs
```

GitHub Actions 会在 push / pull request 时运行相同检查。覆盖 JavaScript 语法、词库范围与去重、草船闯关奖励事务、离线缓存失败与续传、射击绕障路径；这些模型检查不代替真机画面、音频和触控验收。

游戏 10.13-01 的历史验收为 213 项本地检查、31 个 JavaScript 语法检查、15 项公网回归，见 [验证摘要](10.13-01_验证摘要.json)。此次开源整理保留游戏版本与旧存档；后续检查以每次 CI 记录为准。

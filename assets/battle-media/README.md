# 地球守护战素材包：本地修订与接入说明

更新：2026-10-04。网页版本：10.3-04，离线缓存：v25。

## 游戏背景

怪兽入侵地球城市，试图统治居民并切断救援通讯。奥特曼保护城市，孩子扮演英文通讯员：听课本中的英文问句，选出合适回应，为英雄补充反击能量。三幕依次是接通通讯、护送居民、重启地球护盾。

答对自动播放英雄出击；答错播放怪兽反击。双方各十格血，累计答对十题获胜，累计答错十题落败，答对不抵消已有受伤。连续五题正确触发光束大招，每题仍只扣一格血。答题卡锁定，并显示正确英文和中文；影片结束后点“下一题”。退出保存，重新选择游戏保留已经获得的奖励。

## 播放调度

1. 英文问句优先。播放英文立即取消中文对白和打击音效，背景降低；英文真正结束后恢复背景，取消的对白不补播。
2. 电影确认实际首帧后，才按cue安排蓄力、冲刺、命中和光束声音；加载失败退回网页动作，下一题仍能解锁。
3. 开场三条对白合计约25.8秒，分三段显示。片头5秒与待机画面配合，不把全部配音硬塞进5秒；可点下一段或跳过。
4. 首次答对/答错、阶段变化、五连、危机与胜败对白按每局标记，保存在本地进度；同题只选最重要的对白，不叠加多条口号。
5. 最后一击结束后播放胜利护盾或撤退影片，再释放结果按钮；保存返回或网页进后台停止所有音频、影片和挂起调度。
6. 家长设置可分别开关城市配乐、打击音效和角色对白；偏好保存在本机。原跟读仍纯本地，不上传，不做自动发音评分。

## 文件怎么使用

- 游戏运行清单：`assets/battle-media/manifest.json`；浏览器数据脚本：同目录`manifest.js`（window.BattleMediaData）。其中src相对游戏根目录。
- 运行素材：`assets/battle-media/audio/`、`video/portrait/`、`video/landscape/`。
- 原包的`manifest.json`已改为实际运行版，assets[].file使用`../assets/battle-media/...`，指向游戏中的处理副本；producerDeclared保留旧声明供追溯，不能拿来做同步。
- `manifest.原始备份.json`、`README.原始说明备份.md`保留修订前内容；`manifest.核对版.json`、`README.核对版.md`是此前审阅稿，记录的是接入前状态。
- 可复现脚本：工作区`work/process-battle-media.py`；游戏声音`battle-audio.js`；视频`battle-film.js`；主流程`training.js`；离线与视频Range响应`sw.js`。

## 验证范围与剩余限制

48个处理媒体都存在且完整解码，H.264与无声格式已核实；浏览器检查实际MP4帧推进、真实MP3解码、英文优先、动作同步、声音取消、胜负累计与奖励防重、多个手机视口、缓存视频206/416及断网重开。

### 草船坐标

坐标相对 PNG 本身，`x / 宽度、y / 高度`，不是相对 CSS 容器。

- 船尾在左，船头在右，船体水平，长宽比约 2.40。
- 左铁环中心约 `(0.160, 0.800)`；右铁环约 `(0.892, 0.785)`。适合绘制相邻首尾之间的短链，链条位于船体下面。
- 帆面提示中心约 `(0.605, 0.430)`，文字区域建议 `x 0.43–0.79、y 0.26–0.56`。
- 船尾空座位约 `x 0.13–0.22、y 0.59–0.70`；需要人物时仅在第一艘船叠加诸葛亮。
- 图片本身没有诸葛亮、箭、喷水、连接链、水面或 UI。这些由游戏渲染并依据状态变化。
- 透明像素范围验证为 `alpha 0–255`；非零 alpha 包围盒 `(26, 17, 1925, 795)`。

### 房间坐标与适配

- 顶部中间为门；墙、桌子、电脑、箱子、植物位于边缘；中间为大面积可走地砖。
- 没有文字、人物、怪物、子弹、血条、星空或星门。
- 推荐完整展示整个房间，视口变化时独立缩放游戏坐标，不把电脑宽屏 CSS 坐标直接套到手机。
- 角落桌子是底图中的装饰；如果需要与玩家碰撞，应由引擎增加相应碰撞范围。
